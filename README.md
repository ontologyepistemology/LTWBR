# LTWBR
WARNING: The code is all over the place because I #FreeStyled this with zero forethought... messiest code ever made, regardless though:
The core gameplay mechanics involve only one button: 
F to parry
You parry until either you or the enemy dies, in either case you have the option to TRY AGAIN, or ESC free your cursor. 
That's the whole loop as of now. I plan to make more assets soon, and an environment beyond gray floor & gray cubes. I'm aware that parrying is difficult, but it IS do-able.
